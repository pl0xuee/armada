# ⚓ Armada

**Command your fleet of AI agents.**

One sleek, gunmetal command deck for running **Claude**, **ChatGPT (Codex)** and **Grok** agents side by side, across all your accounts, on Windows, macOS and Linux.

`status: planning` · MIT licensed · local-first

</div>

---

## What it does

- 🚀 **Launch agents** from Claude Code, OpenAI Codex and xAI Grok Build (plus any [ACP](https://agentclientprotocol.com) agent) into any project
- 👥 **Multiple accounts per provider**: switch with one click, or run them all at once
- ♻️ **Resume anything**: agents survive closing the app, crashes and reboots
- 🔔 **Sounds and notifications** the moment an agent needs your attention, with Approve/Deny right from the notification
- 🛰️ **Mission Control**: watch your whole fleet live in one grid
- 🌳 **Git worktree isolation**, diff review, commit and PR in-app
- ⚖️ **Compare mode**: one prompt, three providers, side by side
- 🎨 Dark, gunmetal-grey design built for long sessions

## Built with

Tauri 2 · Rust · React 19 · TypeScript · Tailwind v4 · shadcn/ui · SQLite · Agent Client Protocol
